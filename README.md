# Zeus Templo Fitness

App web del gimnasio: pagos, socios, grupos, rutinas y ejercicios.

- `index.html`: la app completa.
- `config.js`: conexión con Supabase. Con los valores vacíos funciona como modelo con datos de ejemplo.
- `supabase.sql`: script completo de la base de datos, para una instalación nueva.
- `supabase-2.sql`: actualización para una base ya instalada (semana, registro de entrenamientos y cargas).
